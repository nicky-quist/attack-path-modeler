Build an attack graph from CVEs you already know about

No Nessus scan needed. Name the hosts, list the CVEs on each, and the pipeline pulls CVSS from NVD, exploit probability from EPSS and CISA KEV, applies the segmentation policy, and ranks the chains — same code path as a real scan.

Only real CVE IDs resolve — CVSS is fetched live from the NVD API, and uncached lookups are rate-limited to roughly one every six seconds. Mark a host as a gateway if it bridges network segments. Prefer the terminal? python main_from_cves.py --interactive.
